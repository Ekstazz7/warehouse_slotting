Warehouse Slotting & WMS Engine

Система оптимізації розміщення товарів (slotting) та симулятор термінала Motorola WMS для сектора автозапчастин підвіски.

Опис коду та архітектури проєкту (Warehouse Slotting Engine)

Проєкт являє собою повноцінну інтелектуальну систему управління складом (WMS) для сектору автозапчастин підвіски. Архітектура розділена на модулі в папці src/ та управляється головним скриптом main.py:

models.py (Доменні моделі):
Описує базові сутності через зручні Python dataclasses та Enum: типи важелів підвіски (ArmType), категорії ротації товарів від топу до неліквіду (Rotation), а також типи складських полиць і комірок (ShelfType).
Містить математичні коефіцієнти для розрахунку ефективного об'єму деталей з урахуванням геометрії та наявності індивідуального упакування.

generator.py (Синтетичний генератор даних):
Генерує повний масив каталогу на 5 630 унікальних SKU (з розподілом на категорії R1–R5 та нові товари RN, парні комплекти LH/RH та універсальні деталі UNI).
Розраховує фізичні розміри, вагу, медіани продажів за 6 місяців та партії зберігання.

db.py (Керування базою даних SQLite):
Створює реляційну структуру даних (таблиці shelves, sku_catalog, inventory, overstock).
Налаштовує з'єднання у режимі WAL (Write-Ahead Logging) з тайм-аутами, що дозволяє одночасно читати дані та виконувати запис зі сканера без блокувань (database is locked).
Автоматично розраховує топологічну вартість переміщення (distance_cost) на основі координат стелажів та ярусів.

allocator.py (Рушій двофакторної аллокації):
Розподіляє товари по комірках сектору, спираючись на подвійний фактор: вага + кубатура (з лімітом заповнення до 80%).
Розподіляє надлишки партій, які не вмістилися на робочі полиці або обмежені правилами категорії RN, у буфер надстанів (overstock).

validator.py (Логічний валідатор комірок):
Перевіряє фізичні обмеження перед розміщенням: чи пролізе деталь крізь вікно доступу (entry_height_cm), чи не перевищено ліміт різновидів товарів у боксі, та чи сумісні ротації товарів на одній полиці.

scanner.py (Термінал Motorola WMS):
Симулятор термінала з багаторівневим інтерактивним меню для сканування штрихкодів, перевірки вільного місця на полицях у реальному часі, реєстрації нових товарів та безпечної фіксації розміщень.

tasks.py (Генератор складських завдань):
Формує черги інструкцій для працівників (розміщення на полицях відбору, поповнення, переміщення в надстан) та експортує їх у форматі warehouse_tasks.json для інтеграції з WMS.

main.py (Головний оркестратор):
Запускає повний конвеєр через аргументи командного рядка (--run-all, --rebuild-catalog, --tasks-only).
